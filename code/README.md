# CV Reader

Локальное демо: PDF / Word → текст → DeepSeek → JSON → профиль в React.

## Запуск

```powershell
cd C:\work\CUHK\AIE_1903\code
.\setup.ps1
.\start.ps1
```

Откройте http://127.0.0.1:8000. Если окружение уже настроено, достаточно `start.ps1`.
Требуются Python 3.11+ и Node.js 20.19+; setup.ps1 также находит Python из установленного Codex.

## Использование

1. Upload CV / Choose file либо Use sample CV на пустом экране.
2. Дождитесь извлечения текста и обработки DeepSeek.
3. Откройте Bio, Education, Experience, Awards или Publications.
4. Ссылки p. N / Block N открывают извлечённый текст источника. Original открывает исходный документ.
5. JSON скачивает полный структурированный профиль. Готовые профили сохраняются и остаются после перезапуска.

Пример берётся из `..\data\simple_dataset\CV.pdf`. Он проходит реальную обработку, без заранее зашитых ответов.

## Ключ и модель

Backend читает ключ из `C:\work\DONTDELETE\deepseek_aie1903.txt`. Ключ не копируется в проект, не отправляется в браузер и не выводится в логах.
При обработке извлечённый текст загруженного CV отправляется в DeepSeek. Один запуск обычно делает один запрос; при неверном JSON допускается одна повторная генерация.

Настройки через переменные окружения:

- `DEEPSEEK_API_KEY`: ключ вместо файла.
- `DEEPSEEK_KEY_FILE`: другой путь к файлу ключа.
- `DEEPSEEK_MODEL`: модель, по умолчанию `deepseek-chat`.
- `CV_STORAGE`: другое расположение сохранённых файлов.

Интеграция использует [JSON Output DeepSeek](https://api-docs.deepseek.com/guides/json_mode/) и серверную проверку схемы Pydantic.

## Структура

- `backend/main.py`: загрузка, фоновые задачи, сохранение, API и раздача сборки React.
- `backend/extraction.py`: PDF и DOCX → текст с номерами страниц / блоков.
- `backend/ai.py`: запрос к DeepSeek, JSON mode, проверка источников и обработка ошибок.
- `backend/schema.py`: схема пяти разделов профиля.
- `frontend/src/`: React и стили.
- `storage/<id>/`: оригинал, текст, статус обработки, профиль JSON. Исключено из Git.

PDF: максимум 15 MB и 80 страниц. DOCX: абзацы и таблицы в исходном порядке. Нумерация Word относится к текстовым блокам, поскольку DOCX не содержит стабильных границ страниц. Старые `.doc` нужно сохранить как `.docx`. Сканированные PDF требуют предварительного OCR. Тексты длиннее 120 000 символов отклоняются явно, без скрытого обрезания.

Приложение извлекает сведения из загруженного CV. Внешняя проверка фактов, рейтинги кандидатов, редактирование профиля и интернет-обогащение не входят в эту версию. Ссылки на источники позволяют вручную сверить результат; они не гарантируют точность каждой интерпретации AI. Локальное демо без авторизации, сервер привязан к 127.0.0.1.

## Разработка и проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
# Backend
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
# В другом терминале
cd frontend
npm.cmd run dev
```

Vite проксирует `/api` на Python. Production-сборка: `npm.cmd run build`, затем перезапуск Python.
